# Agent Quality Rubric

A good agent has:
- clear goal;
- when to use;
- inputs to inspect;
- checklist;
- output format;
- stop rules;
- sufficiency criteria.

Bad signs:
- usable for every task;
- duplicates another agent;
- loads the whole project by default;
- mixes planning, implementation, review, and validation;
- treats README claims as proof.
